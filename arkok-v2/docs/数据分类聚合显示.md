## 九、公开悬赏功能详细说明

> 新增于 2026-01-12

### 9.1 功能概述

公开悬赏是一种班级级别的挑战任务，老师发布后会显示在大屏端，学生可以应战。

### 9.2 数据模型

| 字段 | 说明 | 值 |
|------|------|-----|
| `challenges.type` | 挑战类型 | `CLASS` (公开悬赏) / `PERSONAL` (个人挑战) |
| `challenges.status` | 挑战状态 | `ACTIVE` (进行中) / `COMPLETED` (已结束) |
| `challenge_participants` | 应战人记录 | 关联 students 表 |

### 9.3 操作流程

```
1. 老师发布公开悬赏
   ↓
2. 悬赏显示在挑战面板（暂无选手）
   ↓
3. 老师选择应战人（全校学生可选）
   ↓
4. 悬赏显示在大屏端（带应战人姓名）
   ↓
5. 老师判定成功/失败
   ↓
6. 悬赏从大屏消失
```

### 9.4 挑战面板 (ChallengePage.tsx)

| 模式 | Tab名称 | 过滤条件 | 功能 |
|------|---------|----------|------|
| 个人挑战 | 发布个人挑战 | `type === 'PERSONAL'` | 选择学生 → 发布 → 判定 |
| 公开悬赏 | 公开悬赏区 | `type === 'CLASS'` | 发布 → 选择应战人 → 判定/取消 |

### 9.5 公开悬赏卡片按钮

| 状态 | 显示按钮 | 点击效果 |
|------|----------|----------|
| 无应战人 | "选择应战人" + "取消悬赏" | 添加应战人 / 取消悬赏 |
| 有应战人（未判定） | "成功" + "失败" | 判定结果 |
| 已判定 | "已结束" 标签 | - |

### 9.6 大屏端显示 (DataDashboard.tsx)

| 条件 | 显示内容 |
|------|----------|
| 有应战人 | `⚔️ 姓名 应战中` |
| 无应战人 | `等待应战...` |

### 9.7 自动消失逻辑

公开悬赏在以下情况会从大屏消失：
1. 点击"取消悬赏"按钮
2. 判定应战人成功/失败

**实现方式**: 将 `challenges.status` 设为 `COMPLETED`，大屏端只查询 `status === 'ACTIVE'` 的悬赏。

### 9.8 相关 API

| 操作 | API | 方法 |
|------|-----|------|
| 发布悬赏 | `/challenges` | POST |
| 添加应战人 | `/challenges/join` | POST |
| 判定结果 | `/challenges/participant/batch` | POST |
| 取消悬赏 | `/challenges/:id` | PUT (status=COMPLETED) |
