系统功能操作手册

Release 2026 最后更新：2026年1月7日 适用角色：校长、老师、教务

核心驱动：游戏化行为塑造

1. 积分与经验值系统

核心

功能特点

  • 双轨制：积分（换实物）与经验值（升荣誉等级）。
  • 全覆盖：涵盖学科、习惯、互助、家庭等9大类任务。
  • 多维度：关注结果，更关注过程（预习/计划）。

核心价值

  • 降低管理难度：用规则替代“碎碎念”。
  • 激发内驱力：从“要我学”变“我要学”。
如何使用： 老师发布任务（如“专注力挑战”） -> 学生举手/系统申报 -> 老师一键通过 -> 触发升级特效。

2. 沉浸式 PK 竞技

热门

功能特点

  • 支持古诗、单词、口算等1V1或多人对战。
  • 即时胜负判定，实时展示分数条。

核心价值

  • 激活氛围：枯燥死记硬背变刺激竞技。
  • 心流体验：高强度专注中完成练习。
如何使用： 课堂间隙点击“开启PK” -> 选择两名/多名学生 -> 大屏展示实时进度。

3. 连胜系统 (Streak)

核心

功能特点

  • 连击特效：连续达标触发火苗（x3, x10...）。
  • 中断惩罚：一旦出错/未达标，火苗熄灭。

核心价值

  • 固化品质：倒逼孩子养成极致细心。
  • 自我要求：为了保住荣誉而主动检查。
如何使用： 系统自动判断每日作业结果，连续全对自动累计连胜天数。

4. 五维内力技能树

功能特点

  • 能力具象化：检查=“雷达眼”，逻辑=“逻辑力”。
  • 技能升级：动作做得越多，熟练度越高。

核心价值

  • 满足炫耀心理：像收集装备一样学习。
  • 软实力培养：关注自驱、规划、内省。
如何使用： 学生完成特定动作（如主动检查） -> 老师确认 -> 系统点亮对应技能图标。

5. 数字化勋章荣誉系统

新增

功能特点

  • 虚拟奖状：如“进步之星”、“阅读达人”等电子勋章。
  • 永久记录：勋章展示在学生个人档案的荣誉墙上。
  • 仪式感：授予时大屏会有全屏动画弹窗。

核心价值

  • 肯定努力：不只看分数，更奖励过程和进步。
  • 仪式感：类似班级发奖状，增强自信心。
如何使用： 老师在评语页或周结时，选择学生 -> 点击“授予勋章” -> 选择勋章类型。

6. 定制化挑战系统

新增

功能特点

  • 量身定制：针对具体问题（如粗心、上课说话）发布挑战。
  • 契约精神：学生接受挑战，形成“师生契约”。
  • 目标导向：设定明确的达成条件（如连续5天无提醒）。

核心价值

  • 克服弱点：将缺点转化为具体的改进目标。
  • 个性化成长：关注每个孩子不同的进步点。
如何使用： 老师发现问题 -> 发布“改掉粗心”挑战 -> 设定周期与奖励 -> 学生接受挑战。

教学与管理：服务标准化

7. 智能签到考勤

基础

功能特点

  • 一键全选/分组批量签到。
  • 个人页自动汇总月度异常（未到/请假）。

核心价值

  • 极致效率：解决放学接送时的混乱。
  • 账目清晰：退费、餐费结算无争议。
如何使用： 接校时勾选“全选” -> 确认 -> 校长可随时在学生详情页查看月度统计。

8. 教室 HUD 数据大屏

亮点

功能特点

  • 实时展示积分榜、连胜榜、PK结果。
  • 视觉焦点，展示“本周悬赏令”。

核心价值

  • 管理神器：用集体注意力解决纪律问题。
  • 荣誉可视：微小进步都能被集体看见。
如何使用： 硬件连接电视/投影 -> 登录系统大屏端 -> 自动轮播。

9. 备课过关系统

核心

功能特点

  • 结构化备课（基础+核心教法+加餐）。
  • 一键批量分发任务。
  • 移动端极速勾选“过关”。
  • 高度自由：根据机构特色灵活新增、删除内容。
  • 预制资源：内置9大类核心教学法和综合成长任务库，开箱即用。

核心价值

  • 服务标准化：避免“换老师即换机构”。
  • 植入核心教法：体现专业度。
  • 灵活定制：适配各类托管机构特色需求。
如何使用： 上午：老师点选发布计划 -> 下午：学生完成后，老师点击“通过”。

10. 全学期过关地图

功能特点

  • 数据留痕：记录每一课生字、错题。
  • 可视化：地图形式呈现学期进度。

核心价值

  • 资产留存：新老师看图即知学情。
  • 精准辅导：基于红点（未过关）复习。
如何使用： 期中/期末调取地图 -> 查看未过关节点 -> 针对性训练。

11. 习惯打卡系统

功能特点

  • 行为量化（坐姿、书写、收纳等）。
  • 生成月度习惯养成报告。

核心价值

  • 素质外化：将“管得好”转化为数据。
如何使用： 发现好/坏习惯 -> 随时在手持端记录 -> 月底生成报告。

家校互联：信任与裂变

12. 分级阅读计划追踪

新增

功能特点

  • 分级计划：按年龄段（绘本/桥梁书/名著）定制。
  • 进度同步：记录书名、页数（P25-P40）、时长。
  • 生成“数字书房”及阅读报告。

核心价值

  • 差异化：从管作业升级为管素养。
  • 量化“静心”：证明托管的高质量。
如何使用： 建立阅读档案 -> 每日离校前录入页数时长 -> 自动推送到家长端。

13. 家长端“物流式”动态

核心

功能特点

  • 节点推送：计划发布→基础过关→技能点亮。
  • 细节呈现：展示具体任务内容、勋章。

核心价值

  • 打破黑盒：像查快递一样看服务。
  • 建立信任：感知机构专业度。
如何使用： 系统自动根据老师的操作，实时触发微信/APP消息推送。

14. 挑战复活与裂变机制

营销

功能特点

  • 复活机制：挑战中断（如21天全对）时可用。
  • 社交助力：家长发圈（晒娃/求赞）获取能量。

核心价值

  • 高级软广：利用“不忍心”和“晒优秀”心理。
  • 高口碑传播：营销转化为对成长的守护。
如何使用： 挑战失败弹出复活窗 -> 家长点击分享 -> 朋友圈助力复活。
